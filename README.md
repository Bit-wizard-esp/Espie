О проекте
ESPeer8 — портативное устройство на ESP8266 для чтения, эмуляции и брутфорса iButton ключей серии DS1990A/DS2401. Всё управление — через OLED дисплей и 4 кнопки. Ключи сохраняются в EEPROM (до 10 штук).

Проект разработан в Arduino IDE.

🔧 Компоненты

Микроконтроллер: ESP8266 (NodeMCU / Wemos D1 Mini)
Дисплей: OLED 128×64, SSD1306, I2C
Кнопки: 4 штуки (UP, DOWN, OK, BACK)
Интерфейс iButton: через GPIO0 (чтение) и GPIO2 (эмуляция)

🚀 Установка

Клонируйте репозиторий:

bashgit clone https://github.com/ВАШ_НИК/espeer8.git

Откройте espeer8.ino в Arduino IDE
Установите все библиотеки из списка выше
Выберите плату: Tools → Board → ESP8266 Boards → NodeMCU 1.0 (или вашу)
Выберите порт и нажмите Upload

💡 Как пользоваться
Чтение ключа

Главное меню → READ KEY
Приложи iButton к контакту на GPIO0
Нажми OK чтобы сохранить, или BACK чтобы отменить

Эмуляция

Главное меню → EMULATE
Выбери ключ из памяти кнопками UP/DOWN
Нажми OK — устройство эмулирует ключ на GPIO2 в течение 10 секунд

Брутфорс

Главное меню → BRUTFORCE
Устройство покажет количество ключей (27 встроенных + сохранённые)
Нажми OK — начнётся перебор с интервалом 500 мс
BACK — остановить

Просмотр кода ключа

Главное меню → VIEW CODE
Выбери ключ → OK
Отобразится HEX-код и результат проверки CRC


🧠 Встроенные ключи для брутфорса
В прошивке предусмотрено 27 встроенных ключей из базы часто встречающихся значений DS1990A. При брутфорсе к ним автоматически добавляются все сохранённые пользователем ключи.

⚠️ Известные проблемы

WRITE KEY не работает — запись на перезаписываемые метки iButton пока не реализована корректно. Ведётся разработка.
